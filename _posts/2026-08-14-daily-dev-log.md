## Today's Update

Three programs closed today, which is unusual. Most days involve moving several things forward simultaneously; today was about bringing discrete bodies of work to a defined end state and making sure the evidence behind each closure is actually traceable.

The largest body was the MCP boundary and SDK modernization — 48 planned work units plus roughly 28 additional follow-on items that emerged during review. The remediation ran the full stack: freezing the MCP-only authority invariant as a hard constraint, amending ADR-0337 to reflect that agents reach the platform exclusively through MCP (no direct routes, no alternate tool paths), then building every enforcement layer that invariant demands. That meant a universal agent route admission guard, bidirectional policy and handler coverage, and a negative authorization matrix that proves the denials, not just the happy path. File-transfer tools got their own treatment — normalizing the tool contracts, routing execution through the governed layer, retiring the direct agent routes, and then writing explicit tests that confirm bypass attempts and tenant denials produce the right outcomes. The TOON codec work ran in parallel: separate PHP and TypeScript implementations of the strict official TOON codec, cross-language conformance fixtures, manifest migration for active `.toon` files, and a token-savings gate that becomes a blocking surface check rather than an advisory. The capability graph got a transport-neutral `CapabilityGraph` model with adapters on both the PHP and TypeScript sides and a cross-language contract test enforcing they stay consistent. By the end, the runtime was locked down too — fail-closed host launch adapters, proven process and filesystem denials, proven network and alternate-tool denials, runtime drift response, and an end-to-end gate that makes the whole matrix blocking. Artifacts compile into separate internal MCP and Tenant Headless bundles; the Tenant Headless clients are generated into `@colossalistic/sdk` with their own negative tests proving the external authority boundary holds. I'm genuinely uncertain whether the dual-codec negotiation logic (explicit legacy JSON fallback alongside official TOON) will age well — it's the right call right now for any tooling that hasn't migrated yet, but it's the kind of thing that tends to linger past its intended lifetime if there's no forcing function on the legacy side.

The residual discovery program closed through both phases. Phase 0 covered the foundational contract layer: prospective expectation contracts, assessment contracts, a billing usage observation contract, tenant-local calibrated assessment envelopes, and shadow-mode capture to prove the assessment pipeline produces stable output before anything touches live data paths. The Phase 0 exit gate is explicit — passing it is a precondition for Phase 1. Phase 1 then built the operational surface: protocols, domain bindings, activation and readiness checks, source-owned analysis projections with reconciliation, bounded interpretable discovery runs, and the full candidate/confirmation/hypothesis lifecycle. The governed surfaces — Workbench, OIW, API, and MCP — all exist as distinct delivery targets. Typed promotion handoffs authorize what moves between phases, and the Phase 1 exit gate is tenant-local, meaning a tenant's own data state determines passage rather than a global signal. Closeout published phase dispositions and archived the program. The archive indexing matters here: future operators running discovery for the first time will have a clear record of what each phase was supposed to prove and whether it did.

Beyond those two programs, the day included HS-202's merge gate (attaching remote CI evidence and confirming a conflict-free merge), remediation of HS-186 branch review findings, stabilizing admin surface workflows and addressing regressions found in review, tightening residual discovery contract documentation, hardening delivery reconciliation evidence, closing escalation recovery gaps, file-transfer tenant migration preflight and constraint failure verification, and a set of focused MCP refinements — narrowing delegation principal IDs, scoping delegation replay by tenant, rejecting nonpositive boundary timeouts, preserving boundary refusal errors through the full response path, and enforcing that the token benchmark actually fails when the savings threshold isn't met rather than producing a passing result with a warning. That last one is the kind of detail that looks minor but determines whether the gate has teeth. ADR-0336 was introduced to define the federated cross-tenant residual research boundary, and outdated TV587–TV606 order-of-operations documentation was removed rather than updated — it described a sequencing that no longer applies, and leaving it around would create confusion during implementation.

What this enables concretely: the MCP-only invariant is now enforced at every layer with evidence, not just declared in an ADR. Future agent integrations don't have a "direct route" option to reach for. The residual discovery archive gives the next implementer a phase-structured record of what was proven and what the handoff contracts require. The things I'd watch: the legacy codec fallback path needs a sunset plan, and the admin surface regressions addressed today suggest the review cycle on that surface probably needs to tighten before the next batch of workflow changes goes in.
